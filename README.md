# c-o-guia-digital

Projeto Cão Guia Digital

O projeto surge a partir da baixa visibilidade e falta de divulgação do Programa Cão-Guia do IF Goiano, o que acaba dificultando sua continuidade, crescimento e impacto social. Essa falta de divulgação faz com que muitas pessoas desconheçam a existência do programa, suas atividades e a importância dos cães-guia. Além disso, há uma carência de informação sobre como interagir corretamente com cães-guia, o que pode prejudicar o trabalho dos animais e comprometer a segurança dos usuários. 

O projeto Cão-Guia Digital tem como objetivo criar um portal web interativo para divulgar o Programa Cão-Guia do IF Goiano, promovendo conscientização, facilitação de doações e engajamento social. O site fornecerá informações sobre a história dos cães, processo de treinamento, depoimentos de beneficiários e opções para voluntariado e doações.
